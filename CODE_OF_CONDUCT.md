# Code of conduct

Be kind and be useful. Assume good faith, keep feedback about the work rather than the person,
and don't harass, demean or exclude anyone. This follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Maintainers may remove comments, issues or contributions that break these rules and may block
repeat offenders. To report a problem, use the private
[security advisory form](https://github.com/Echo-Storm/Runtime_Forge/security/advisories/new)
(it reaches the maintainer only) or contact the maintainer through their GitHub profile.
